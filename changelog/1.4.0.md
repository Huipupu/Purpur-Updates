# Purpur 1.4.0

- 安装包从约 270 MB 缩小到约 74 MB，只带云端功能，装好就能用。要用本地模型（Qwen3-TTS、Paraformer-zh），在插件「设置 → 本地模型」里装本地模型组件：CPU 版，或有 NVIDIA 显卡时的 GPU 加速版。优先从国内镜像下载，每个文件都校验；断网、取消或关掉窗口后，回来点「继续」接着下。
- 新增 DaVinci Resolve Studio 版（测试版）：语音克隆、音效生成和字幕合成都能在 Resolve 里用，字幕直接放到字幕轨 1。安装时检测到 Resolve Studio 会一起装上。
- 转录默认改用豆包云端识别，安装包内置识别 Key，不用填 Key、不用下载模型就能转录；超过 100 MB 的音频和 flac 等格式会先自动转换再上传。
- 字幕编辑器加入校对工具箱：查找替换、一键排版、问题跳转、原稿对照。校对前先在本地找出原稿与转录的写法差异，交给模型逐条判断；中英混排句子的字幕时间更准。
- 第一次打开有设置向导和功能演示视频，字幕页有操作引导，「设置 → 插件信息」里可以再看一遍；演示页可以直接打开完整的使用说明书。
- 全新的安装界面。升级时保留设置、音色库和模型目录，已经在用的本地模型照常能用、不用重新下载；卸载时可以选择保留音色库、合成历史和 Key，重新安装后自动恢复。同时打开 Premiere Pro 和 After Effects 时共用一个后端，不会再互相关掉。
- 后端启动失败时，面板会说明原因和处理办法，不再反复进入「首次安装配置」。修复豆包音效把描述文字读出来、拆条后边听边改高亮错行等问题。

安装包未做代码签名，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」即可。
